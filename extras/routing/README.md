# Rutas

Módulo propuesto para caminar, conducir y combinar transporte. El grafo debe construirse desde calles y caminos con sentidos, conexiones, cruces y restricciones documentadas.

El cálculo de ruta no está incluido todavía. Para caminar en Miami-Dade habrá que verificar cobertura de aceras, cruces, puentes y accesos antes de presentar un trayecto como ruta peatonal precisa.
