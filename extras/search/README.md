# Búsqueda

Módulo propuesto. Buscará calles, direcciones, lugares y nombres de barrios sobre un índice propio construido a partir de fuentes documentadas.

El módulo debe devolver coordenadas, nombre canónico, tipo de resultado y fuente del registro. No consulta todavía servicios de búsqueda externos. Faltan inventariar las capas autorizadas de direcciones, POI y municipios para crear el índice inicial.
