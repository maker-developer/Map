# Visor de iOS

La primera versión del proyecto es el visor web. Cuando el estilo y los PMTiles estén estabilizados, esta carpeta albergará un visor nativo de comprobación.

MapLibre Native para iOS puede leer PMTiles desde una URL o desde archivos locales del bundle con el protocolo `pmtiles://`. Los archivos locales caben en pruebas sin conexión. Las fuentes PMTiles no admiten los paquetes de descarga offline administrados por MapLibre, así que las descargas de regiones deben diseñarse aparte.

- [Primer mapa SwiftUI con MapLibre](https://maplibre.org/maplibre-native/ios/latest/documentation/maplibre-native-for-ios/gettingstarted/)
- [PMTiles local y remoto en iOS](https://maplibre.org/maplibre-native/ios/latest/documentation/maplibre-native-for-ios/pmtiles/)
